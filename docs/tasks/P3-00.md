现状事实（每条附实测证据；环境：WSL2，独立测试库 chat_test（sql/chat.sql 经 sed 改库名初始化，开发库 chat 未触碰），服务器 `~/muduo-chat-build/debug/bin/ChatServer`（commit 5373503，`setarch x86_64 -R` 启动，v1=6000/v2=7000 由 config 指定 db.dbname=chat_test），客户端脚本 /tmp/p3-00-evidence.py（不入库），结束 SIGTERM 干净退出）：

- **重复 one-chat 产生两行**（E1）：同 payload 对离线目标发两次 → `SELECT id,userid,message FROM OfflineMessage ORDER BY id` 返回两行、内容逐字节相同（id=1,2 同 message）。源码：`MySQLMessageRepository.cpp:50` 每次 INSERT，无幂等键。
- **在线路径不落库**（E2）：目标登录在线后发送 → 发送者 errno=0 + 目标端原样收到转发；COUNT(*) 保持 2（E1 行数不变）、userid=1 的行 = 0。源码：`ChatService.cpp:325-336`。
- **登录取走即删除**（E3）：alice 登录 → LOGIN_MSG_ACK errno=0 + 两条补投；登录后 COUNT(*)=0。源码：`MySQLMessageRepository.cpp:139` DELETE WHERE userid=?。
- **群查询失败仍 ACK 0**（E4）：`{"msgid":10,"id":1,"groupid":99999,...}` → 回 `{"errno":0,"groupid":99999,...}`（成员查询为空仍无条件 0）。源码：`ChatService.cpp:483-486`。
