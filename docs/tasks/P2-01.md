## 接口/行为

- `app/Command.hpp`：Command{type, userId, name, password, raw} + SessionContext{connId}；
  不把 JSON 字段名当领域模型。
- `app/Reply.hpp`：领域 Reply{type, errnoCode, errmsg, userId, name}（Errno 分类见 CONTEXT.md）。
- `app/UserRepository.hpp`：port（create → CreateUserResult{ok, id, error: NameExists/StorageFailure}）。
- `app/ChatApplication.hpp`：handle(SessionContext, Command, Reply) 编排用例（当前仅注册）；
  注册校验：空 name/空 password/超长名（>50，对齐 VARCHAR(50)）→ errno=1 "invalid input!"。
- `app/InMemoryUserRepository`：内存 adapter（测试/开发用，无 MySQL）。
- `LegacyUserRepository`：现网 MySQL adapter，SQL 语义与 P2-00 前 ChatService::reg 完全一致
  （查重名 → INSERT → insert_id）；真实 seam 形成，P2-02 替换为直接 MySQL adapter。
- `ChatService::reg` 委托 ChatApplication + LegacyUserRepository；网络层不接触 MySQL 类型。
- 构建：新增 `chatserver_core` STATIC 库（app 层，无 MySQL 依赖），ChatServer 与测试共用；
  P1R-01 单编译检查保持（compile_commands：app 源与 LegacyUserRepository.cpp 均单条目）。
- 行为变更（已记入矩阵 B-04）：空名/空密码/超长名注册从"现状可注册"变为 errno=1。
