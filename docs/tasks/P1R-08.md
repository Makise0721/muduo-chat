## 问题与证据

审查报告 F-06：队列只保存 (level, string)，输出无结构化 context；消费端逐条写且
flush 型输出（std::endl），无批量/double-buffer；无同步 vs 异步对比 benchmark。
Logger.cc:129 用 `<< std::endl`（逐条 flush）；run() 单条取队列（:98-100）。

## Interface / 可观察行为

```cpp
struct LogEvent {
    Timestamp timestamp;      // 入队前固定
    int level;
    std::thread::id threadId; // 入队前固定
    std::string component;
    std::string eventName;
    std::string message;
};
void log(int level, const std::string &component, const std::string &eventName,
         const std::string &message);
using SinkCallback = std::function<void(const std::vector<LogEvent> &)>;
void setSinkCallback(const SinkCallback &cb);  // test recorder adapter
```

- LOG_* 宏调用点零改动（宏内部改调 4 参版本，component 空、eventName=宏名）；
- 单消费者按 batch（≤64）取队列、批量写（移除逐条 flush：endl → '\n'）；
- 默认输出格式不变（前缀 + timestamp + message）；test recorder 经 setSinkCallback
  断言结构化字段；
- 队列满 drop policy、FATAL 必达、flush 语义不变。
