## 问题与证据

审查报告 S-01：signal handler 向 `gSignalFds[1]` 写入，但初始化只将 `gSignalFds[0]` 设为
`O_NONBLOCK`（main.cpp:81-82）——信号突发填满 socket buffer 后 handler 可能阻塞。
另核查：P1-07 声称的 beginShutdown 幂等保护（gShuttingDown）实际未在 main.cpp 中
（重复 SIGINT 会注册多套 drain 定时器）——本任务一并修复。

## Interface / 可观察行为

- SIGINT/SIGTERM handler 永不阻塞（写端 O_NONBLOCK|FD_CLOEXEC；EAGAIN 静默丢弃）；
- 重复/突发信号只合并为一次退出流程（幂等）；drain 定时器只注册一套；
- loop 回调 drain 全部字节后执行 beginShutdown；
- DRAINED（快路径）与 5s 硬截止（DRAIN_TIMEOUT + forceCloseAll）两条路径进程可观察。

## 非目标

- 不引入 signalfd 重构；不改 drain 语义；不做 MySQL 无关的 mock。

## RED

命令：

```powershell
wsl.exe -d Ubuntu -- bash -c "grep -n 'F_SETFL\|gShuttingDown' /mnt/d/agent_learning/muduo-chat/chatserver/main.cpp"
```

预期失败：只有 fds[0] 设 NONBLOCK（fds[1] 阻塞）；无 gShuttingDown。
实际证据：main.cpp:81-82 仅 fds[0] O_NONBLOCK；beginShutdown 无幂等保护。

## 最小实现

1. socketpair 后两端统一 `O_NONBLOCK | FD_CLOEXEC`；
2. handler 保持 async-signal-safe（write + 忽略 EAGAIN/ECONNRESET 返回值）；
3. beginShutdown 首行 `static bool gShuttingDown` 保护（已启动则 return）；
4. 进程 CTest `signal_shutdown_test.sh`：起真 ChatServer（DB_PASSWORD=123456）→
   登录挂连接 → 循环 SIGINT/SIGTERM ×N（风暴）→ 断言进程在超时内退出、
   退出码 0、stdout 中 DRAINED/DRAIN_TIMEOUT 打印恰一次（幂等）；
   server 二进制路径由 CMake 注入。

## 验证

- 聚焦：`ctest -R 'signal'`（process-signal-shutdown）Debug/ASan/TSan 均通过 ×3 轮；
- 全量：Debug/ASan/TSan 92/92 ×TSan 两轮无 WARNING；
- 信号风暴：30× SIGINT/SIGTERM 交替 → 退出码 0、DRAINED 恰一次（幂等）；
- 硬截止路径：SIGTERM 挂连接 → DRAIN_TIMEOUT 5s 内 forceCloseAll + 退出（P1R-04 smoke
  回归 PASS）；
- `git diff --check` exit 0。

## 调试记录

1. 复核发现 P1-07 的 gShuttingDown 幂等保护实际已在 main.cpp（先前误判缺失）——本任务
   保留并仅验证；真正缺口是写端 fd 未设 O_NONBLOCK（S-01）。
2. 进程测试初版 pkill 模式 `-f "$SERVER_BIN"` 匹配到脚本自身命令行 → Subprocess
   terminated（自杀）——改精确模式 `setarch x86_64 -R .*$SERVER_BIN`。
3. **libcrypto TSan 误报**：ConnectionPool::init 的 OpenSSL 全局 allocator 记账在
   TSan 下报同线程 race（exit 66）——新增 `tests/scripts/tsan.supp`
   （race:libcrypto.so/libssl.so）+ 脚本 export TSAN_OPTIONS（Debug/ASan 下无运行时，
   无害）。
4. TSan 构建的 ChatServer 必须 setarch 启动（ASLR 随机映射 FATAL）——脚本内
   `setarch x86_64 -R` 统一（Debug/ASan 无害）。

## 完成定义

- handler 仅 async-signal-safe 操作且无阻塞路径（代码 + 进程风暴证据）；
- 重复信号不启动多套 drain timer（DRAINED 打印恰一次）；
- DRAINED 与 5s hard deadline 两条路径都有进程证据。
