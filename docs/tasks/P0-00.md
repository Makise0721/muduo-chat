```

  -> Configuring done / Generating done（exit 0）

    CMakeFiles/ChatServer.dir/link.txt CMakeFiles/ChatClient.dir/link.txt
  -> 两处均指向 source tree bin（exit 0）

$ grep -o '/mnt/d/agent_learning/muduo-chat/mymuduo/lib/libmymuduo.so' \
    mymuduo.dir/CMakeFiles/mymuduo.dir/link.txt
```

未执行完整 build，避免覆盖已跟踪二进制。

## 最小实现

- 顶层统一设置 `CMAKE_RUNTIME_OUTPUT_DIRECTORY`、`CMAKE_LIBRARY_OUTPUT_DIRECTORY`、`CMAKE_ARCHIVE_OUTPUT_DIRECTORY` 到 `${CMAKE_BINARY_DIR}` 下；
- 删除顶层 `EXECUTABLE_OUTPUT_PATH` 与子目录 `LIBRARY_OUTPUT_PATH` 覆盖；
- 停止跟踪 `mymuduo/lib/libmymuduo.so`，并在 `.gitignore` 精确忽略生成目录/文件。
