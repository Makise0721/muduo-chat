## 问题与证据

审查报告 F-02：`TcpConnection::forceClose()` 直接操作 Channel/callback/fd 状态（loop-affine），
但 `TcpServer::forceCloseAllConnections()` 在 base loop 遍历全部连接直接调用——启用 worker
loops（threadNum>0）后连接属于其他 EventLoop，跨线程操作 loop-affine 对象。现有测试未覆盖
threadNum>0 的 drain/force close，TSan 全绿不能关闭此问题。

## Interface / 可观察行为

- `forceClose()` 可从任意线程调用：loop 线程内同步执行；跨线程经 queueInLoop 调度到
  所属 loop，捕获 shared_from_this()；
- 内部 `forceCloseInLoop()` 保持私有（Channel/fd/callback 全部状态变更仅在所属 loop）；
- 重复 shutdown/forceClose 幂等；close callback 恰好一次；stall timer 与预算清理不变；
- TcpServer::forceCloseAllConnections 在 worker loops 场景下由各 owner loop 执行关闭。

## 非目标

- 不改变 forceClose 语义（回调顺序、状态机）；
- 不做通用跨线程执行器（P2-03）。

## RED

命令：

```powershell
wsl.exe -d Ubuntu -- bash -c "sleep 2; cmake --build ~/muduo-chat-build/debug --parallel 2>&1 | tail -1"
```

预期失败：新测试 ForceCloseFromOtherThread（TcpConnection forceClose 从非 loop 线程调用）
——当前实现直接操作 loop-affine 对象（无调度），TSan 下应暴露跨线程访问。
实际证据：直接调用的现状在跨线程下无同步边（代码审查确认）；测试先写为预期行为。

## 最小实现

1. TcpConnection：`forceClose()` → `loop_->runInLoop(bind(&TcpConnection::forceCloseInLoop,
   shared_from_this()))`；新增私有 `forceCloseInLoop()`（原 forceClose 体）；
2. 调用的 loop 线程内场景行为不变（runInLoop 同步）；协议错误路径（ChatServer onMessage）
   不变；
3. TcpServer::forceCloseAllConnections 无需改（forceClose 已线程安全）——仅核对。

## 验证

- 新测试：`ForceCloseFromOtherThreadIsIdempotent`（测试线程直接 forceClose ×3 →
  close callback 恰好一次）；`ForceCloseAllWithWorkersIsLoopAffine`（threadNum=2 +
  3 连接 → base loop forceCloseAll → 3 个 disconnected 回调各一次 + connectionCount 0）；
- `ctest -R 'TcpServer|TcpConnection|Backpressure'` 20/20；ForceClose 套件 4×10 轮稳定；
- 全量：Debug/ASan/TSan 91/91 ×TSan 两轮无 WARNING（worker-loop 跨线程关闭无 TSan 报告）；
- 进程级：SIGTERM 挂连接退出 smoke PASS（DRAIN_TIMEOUT forceCloseAll 路径回归）；
- `git diff --check` exit 0。

## 调试记录

1. TcpServer 无公开"连接关闭"回调——测试用 connectionCallback 的 disconnected 分支计数；
   forceClose 路径 disconnected 回调恰好一次（connectDestroyed 对 kDisconnected 跳过）。
2. forceClose 语义不变：跨线程经 queueInLoop 调度（loop 内同步）；重复调用幂等
   （state 检查）。

## 完成定义

- worker-loop 场景无 TSan 报告；close callback 恰好一次；重复 forceClose 幂等；
- 连接与 timer 均释放（ASan/LSan 干净）；既有语义不回退（89/89）。
