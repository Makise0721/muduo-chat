## 接口/行为

- `FriendRepository` port：`add(userId, friendId) -> AddFriendResult{FriendError{Duplicate, TargetNotFound, StorageFailure, Disconnected, Timeout}}`；
  1452（FK）→ TargetNotFound、1062 → Duplicate；InMemory（有向边 + 用户存在性判定）/
  MySQL（prepared）双 adapter。
- `GroupRepository` port：`create(ownerId, name, desc) -> CreateGroupResult{groupId}`、
  `join(groupId, userId) -> JoinGroupResult`；**建群在 adapter 内显式事务**
  （START TRANSACTION / COMMIT / ROLLBACK：creator 成员插入失败 → 整组回滚，
  不留孤儿群）；join 1452 → TargetNotFound、1062 → Duplicate。
- `ChatApplication` 构造注入三 port；addFriend/createGroup/joinGroup 线程安全透传。
- ChatService 三个入口迁移：executor 异步（SQL 全在 worker），completion 组响应
  （msgid=7/8/9 回显 + errno 0/1 不变）；权限模型现状缺失（B-14/B-18 待ADR），
  契约以 TargetNotFound 覆盖 FK 类错误。
- **修复**：ChatService executor 由 2 worker 改 1 worker——多 worker 并行破坏
  同一连接的串行依赖（addFriend 成功后再重复 add 会被乱序执行成双成功），
  单 worker FIFO 保证业务顺序（P2-10 性能评估后再分片）。
