# P2-09 配置与依赖关闭顺序

状态：VERIFIED
基线：main @ c3ea60e（P2-08 后）
提交：`feat(config): load config fail-fast + ordered shutdown`、docs

## 完成定义

1. **配置加载 fail-fast**：`--config <path>`（可选）JSON 配置覆盖 v1/v2 port、thread count、
   DB 凭据（host/port/user/password/dbname）、pool 容量、executor 容量；
   argv 位置参数（ip port [threadNum]）与 `DB_PASSWORD` env 覆盖配置；
   任何配置非法（文件缺失/坏 JSON/未知字段/类型错/越界）→ stderr `config error: ...` +
   exit(1)，不起服务。
2. **关闭顺序**：SIGINT/SIGTERM → `STOP_ACCEPT` → drain network（连接归零打
   `DRAINED pending=0`；超时 forceClose 打 `DRAIN_TIMEOUT`；forceClose 后仍不清零再等一
   周期强制）→ `EXECUTOR_SHUTDOWN`（stop submissions + drain：executor shutdown 拒新、
   join 等在途）→ `POOL_SHUTDOWN`（pool shutdown 拒新获取、等租约归还）→ `QUIT_LOOPS` →
   `EXITED`，exit 0。drain 超时由 `CHAT_SHUTDOWN_TIMEOUT_MS` env 配置（默认 5000）。
3. 向后兼容：无 `--config` 时行为与 P2-08 完全一致（ip port [threadNum] + 默认
   6000/7000/1 + pool 5 + executor 1/64 + "123456"）；`DRAINED pending=0`/`DRAIN_TIMEOUT`
   文本不变（P1R-05 signal_shutdown_test 依赖）；threadNum<1 从"钳到 1"改为 fail-fast 报错。

## 实现

- `chatserver/include/app/Config.hpp` + `src/app/Config.cpp`（chatserver_core）：
  AppConfig{v1/v2(ip 继承 v1，仅 port 可配)、db、executor}；`loadConfigFile`（nlohmann：
  未知字段/类型错/范围错逐字段报错，缺字段留默认）、`applyCliOverrides`（ip 非空、
  port [1,65535]、threads>=1）、`applyEnvOverrides`（DB_PASSWORD 非 NULL 即覆盖）。
- `ChatService::bindLoop(loop, workers, queueCapacity)`：executor 容量来自配置。
- `main.cpp`：`--config` 任意位置解析 + 位置参数/环境合成；关闭顺序重构
  （ShutdownFlow：runEvery 50ms 查 pending==0 → finishShutdown；runAfter 超时 forceClose，
  再超一周期强制）。finishShutdown 在 loop 线程执行：executor shutdown join worker 期间
  completion 仅 queueInLoop 入队（不阻塞）；pool shutdown 在 worker join 后（租约全归还）
  立即返回。

## 风险/决策（记录）

- 关闭瞬间在飞链式任务（如群聊成员查询 completion 再 submit 离线入库）会被
  RejectedShutdown 拒绝——消息丢失是关闭语义的固有部分，记录不修。
- finishShutdown 在 loop 线程 join worker：无死锁（completion 入队不阻塞，见"实现"）。
- 配置文件未知字段 fail-fast（防拼写错误静默失效）。
- 测试过程中修复：v2 默认端口（AppConfig 构造赋 7000）；server 顶层键漏检（补
  checkKnownFields）；测试自身两处笔误（多余 `}`、env 覆盖测试未先 unsetenv）。
