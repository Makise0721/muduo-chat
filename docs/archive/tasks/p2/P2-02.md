## 接口/行为

- `UserRepository` port 扩展：UserError 增 InvalidInput/Disconnected/Timeout；
  防御式输入检查 `isRepositoryInputValid`（NUL 与超长 → InvalidInput，InMemory 与
  MySQL 两 adapter 一致）。
- `MySQLUserRepository`（新）：prepared statement（INSERT ... VALUES(?, ?)，
  自带 bind 数组管理，修复既有 bindParam 的栈生命周期缺陷）防注入；
  `mapMySqlError` 独立映射：1062→NameExists、2006/2016/1053/2003→Disconnected、
  1205→Timeout、1406/1366/1300→StorageFailure、其余→StorageFailure。
- 数据层归位：MySQL.cpp/ConnectionPool.cpp 移入 `chatserver/src/db/` 进
  chatserver_core（P1R-01 单编译保持：全部 chatserver 源 compile_commands 单条目）；
  ChatService 注册路径切换到 MySQLUserRepository；LegacyUserRepository 删除。
- 测试：真实 MySQL 集成（chat_test 独立库，从空 schema 建 User 表，不 skip）；
  契约在 InMemory/MySQL 双 adapter 上共用。
