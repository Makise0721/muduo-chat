# P2-04 连接池有界获取与关闭

状态：VERIFIED
基线：main @ 3e190e2（P2-03 后）
提交：`fix(storage): bound connection-pool acquisition`

## 接口/行为

- `ConnectionPool::acquire(int64_t timeoutMs) -> AcquireResult{ConnectionLease, PoolError}`
  PoolError{None, Timeout, Shutdown, ConnectionFailed}；不允许无限等待
  （timeoutMs<0 保留但标注不推荐）；
- `ConnectionLease`：RAII 租约，仅可移动，析构自动归还；
- `shutdown()`：幂等，拒绝新获取（等待者被唤醒返回 Shutdown），有界等待在途
  租约归还（5s 上限）；
- 坏连接替换：acquire 时 mysql_ping 校验，失败丢弃并新建（建连失败 →
  ConnectionFailed，池容量 -1）；替换在锁外执行；
- `metrics()`：{total, idle, active} 可读取；
- 存量迁移：`getConnection()`/`MySQLConnectionGuard` 删除，ChatService 9 处 +
  MySQLUserRepository 全部改 `acquire(5000)`（DB 不可用 → errno=1 "db unavailable!"
  稳定响应，不再无限阻塞）；MySQLGuards.hpp 保留 result/escape/stmt 守卫；
- 测试基建：gtest 统一经 CROSSCOMPILING_EMULATOR 注入 tsan.supp
  （gtest_discover_tests 的 PROPERTIES 在 CMake 3.28 模块中不写入生成文件，
  改用 `env TSAN_OPTIONS=... setarch ...` 前缀；libcrypto 分配器记账单线程
  TSan 误报与 signal/fd/domain 脚本同一 suppression）。
