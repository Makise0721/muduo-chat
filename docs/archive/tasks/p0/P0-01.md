## 问题与证据

项目无任何测试目标：顶层 CMake 只有 ChatServer/ChatClient/mymuduo 三个 target，
无 include(CTest)、无 tests 目录。`ctest -N` 应列出 0 个测试。

## Interface / 可观察行为

- `ENABLE_TESTS=ON`：发现 GoogleTest（`find_package(GTest CONFIG REQUIRED)`）、构建并注册 unit tests。
- `ENABLE_TESTS=OFF`：生产构建不要求 GoogleTest。
- 默认值决定：**ON**（开发 checkout 默认可测；发行构建显式 `-DENABLE_TESTS=OFF`）。
- GoogleTest 是开发依赖，不链接进生产库。

## 非目标

- 不移动或重构生产源码（Buffer 保持原位，测试只包含 mymuduo 头）；
- 不添加 Buffer 之外的测试（P0-02A 开始）；
- 不引入 FetchContent 依赖路径。
