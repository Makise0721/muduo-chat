## 问题与证据

P0-01 已覆盖初始状态/append/retrieve/grow 基础契约。以下契约尚无测试：

- compact：retrieve 后利用 prependable 空间原地整理（可经公开 `prependableBytes()` 观察）；
- grow：超容量 resize 后数据完整；
- `readFd` 的 `readv` 双区路径：小数据写入内部 writable 区、大数据跨入 extrabuf；
- `readFd` EOF（返回 0）与错误（返回 -1 且设置 `*savedErrno`）。

`readFd`/`writeFd` 定义在 `Buffer.cc`，当前测试 target 未链接，新增测试将无法链接（RED）。

## Interface / 可观察行为

- `readFd(fd, &savedErrno)`：返回读取字节数；EOF 返回 0；错误返回 -1 并写入 `savedErrno`；
  成功路径下 `readableBytes()` 与 `retrieveAllAsString()` 反映全部读入数据；
- `append` 后经 `retrieveAsString`/`retrieveAllAsString` 取回的数据字节序与内容不变；
- compact 后 `prependableBytes()` 回到 `kCheapPrepend`，数据顺序不变；
- 测试只经公开接口，不读取私有索引。

## 非目标

- 不修改 Buffer 实现（含 readv 双区逻辑、makeSpace 策略）；
- 不测试 `writeFd`（P0-02D 连接场景覆盖）；
- 不新增生产可观测 seam。
