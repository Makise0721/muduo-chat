## Interface / 可观察行为

- `connectEstablished()` 触发一次 connectionCallback；对端关闭后 `handleClose` 触发
  第二次 connectionCallback 与一次 closeCallback（当前实现事实，逐项锁定）。
- 同 loop 线程 `send(msg)`：直接写 fd；全部写出则触发 writeCompleteCallback。
- 大 payload：部分写出 → 缓冲 + enableWriting → highWaterMark 回调一次；
  客户端读空后 handleWrite 排空 outputBuffer → writeCompleteCallback。
- 测试经 socketpair + 独立 EventLoop thread，只观察回调次数/数据完整性，无固定 sleep。
