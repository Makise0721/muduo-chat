## Interface / 可观察行为

- `setThreadNum(0)` + `start()`：不创建线程；`getNextLoop()` 恒返回 baseLoop；
  `getAllLoops()` 返回 {baseLoop}。
- `setThreadNum(N)` + `start()`：创建 N 个 EventLoopThread；`getAllLoops()` 返回 N 个
  worker loop（创建顺序）；`getNextLoop()` 按 0..N-1 round-robin。
- 每个 worker loop 可经 `queueInLoop` 接收任务（loop 已运行）。
- pool/thread 析构：quit + join，无悬空；析构后可安全返回主线程。
- 测试只经公开接口。
