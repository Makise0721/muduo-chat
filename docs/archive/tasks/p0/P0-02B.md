## Interface / 可观察行为

- `runInLoop(cb)`：loop 线程内调用 → 直接同步执行（返回前已执行）；
  其他线程调用 → 与 queueInLoop 等价（在 loop 线程异步执行）。
- `queueInLoop(cb)`：任何线程可调；回调在 loop 线程执行；先入先出；每个回调恰好一次。
- `quit()`：loop 线程内设置标志；其他线程调用会 wakeup 并终止 loop。
- 测试只经公开接口，不读取私有容器；同步用 future + 有界 wait_for，不靠固定 sleep。
