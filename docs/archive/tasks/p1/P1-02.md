## 问题与证据

当前 `ChatServer::onMessage`（ChatServer.cpp）内联按 `\n` 切行；发送方向 ChatService
统一 `send(json + "\n")`。无 v2 线协议入口。按 EVOLUTION_PLAN §4.2 双 listener：
`:6000` v1 newline JSON、`:7000` v2 binary frame，业务侧零改动。

## Interface / 可观察行为

- `LegacyJsonLineCodec::decode(Buffer*, std::string*) -> bool`：完整行（含 `\r\n` 兼容）
  取出返回 true；不完整返回 false 且不消费。
- `BinaryFrameCodec::decode(Buffer*, std::string*) -> CodecResult`：
  `Message`（body 即消息，恰消费一帧）/ `NeedMore`（不消费）/ `ProtocolError`（不消费）。
- `TcpConnection::setOutputEncoder(cb)`：send 内容经 cb 变换后写出（v2 连接包 frame）；
  不设置则原样（v1 契约不变）。
- ChatServer 双实例（6000 LegacyLine / 7000 BinaryFrame）共用 ChatService；
  协议不跨端口降级。
- 发送方向业务不变：v2 客户端收到的 body 可能含尾部 `\n`（JSON whitespace，客户端 trim）。
