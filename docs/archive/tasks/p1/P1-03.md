## 问题与证据

EventLoop 无计时器接口（EVOLUTION_PLAN §4.5：心跳、超时、重试统一模块）。

## Interface / 可观察行为（EVOLUTION_PLAN §9 P1-03）

- `EventLoop::runAfter(delayMs, cb) -> TimerId`：一次性，到期在 loop 线程执行；
- `EventLoop::runEvery(intervalMs, cb) -> TimerId`：重复，按**计划时间**推进
  （expiration + interval），不累计漂移；
- `EventLoop::cancel(TimerId)`：取消后回调不执行（含已到期待执行）；
- 任意线程可注册/取消；回调恰好在 loop 线程执行；
- 相同 deadline 的 timer 按注册顺序执行；
- 实现基于 monotonic clock + timerfd 唤醒 + 最小堆/有序容器。
